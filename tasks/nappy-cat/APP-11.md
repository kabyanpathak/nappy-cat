**Type:** Task

**Stage:** 9. GUI polish and release

**Priority:** Normal

**Status:** Planned

**Dependencies:** [APP-10](../nappy-cat/APP-10.md), [PROGRESS-3](../progress/PROGRESS-3.md)

## Goal

Finish a deliberately bounded set of skins, animations, and companion interactions after Spotify.

## Acceptance criteria

- [ ] Choose and record the remaining cosmetic scope before implementing it; additional ideas return to the future-ideas list.
- [ ] New cosmetics use the same persistent unlock/selection behavior without gating productivity tools.
- [ ] Assets have clear licensing and fit the resource budget; reduced-motion equivalents remain usable.
- [ ] Existing timer, task, and music flows remain readable and stable with the new presentation.
