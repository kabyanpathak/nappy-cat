# PROGRESS-3: Award persistent cosmetic progression

**Type:** Task

**Stage:** 5. First extras

**Priority:** Normal

**Status:** Planned

**Dependencies:** [PROGRESS-2](../progress/PROGRESS-2.md)

## Goal

Provide a small, understandable reward system based on recorded usage or completed focus work.

## Acceptance criteria

- [ ] Choose initial milestones and explain what activity counts toward each reward.
- [ ] Unlocks occur once, survive restart, and remain correct after duplicate events or recovery.
- [ ] Rewards and selected cosmetics work offline, without punitive loss of earned progress.
- [ ] Core productivity tools stay available regardless of progress; presentation and additional skins remain separate work.
